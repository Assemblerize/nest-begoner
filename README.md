Nest Begoner

A mod for Factorio 2.1

Eco-friendly artillery: Adds a building that protects the surrounding area from new biter nests spawning within a given radius.

It does not destroy existing nests, nor does it prevent biters from attacking your base.

Not a cheat: Repelling biters comes with a cost. It increases evolution, and expansion groups will simply look for a nest site elsewhere. Also, the building itself is quite power-hungry.
